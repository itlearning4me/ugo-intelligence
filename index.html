Architecture

Seven layers, one pipeline

Each day's brief moves through seven distinct stages: ingestion, processing, a knowledge graph, a multi-agent reasoning pipeline, scoring, synthesis, and delivery. Nothing skips a stage.

  1. 01

    Ingestion ingestion/

    6,000+ RSS feeds, APIs and data sources polled continuously

  2. 02

    Processing processing/

    Near-duplicate detection, credibility scoring, classification

  3. 03

    Knowledge knowledge/

    Entity extraction and a relation graph: who's connected to what, and how

  4. 04

    Agents agents/

    A multi-agent pipeline reasons from trend → problem → opportunity → solution

  5. 05

    Scoring scoring/

    Opportunities ranked on real, data-driven signals, not a model's gut feel

  6. 06

    Brief brief/

    Synthesized into a single, structured daily brief with an AI-ready export

  7. 07

    Delivery delivery/

    Emailed and served through a web API, every morning

Design principle

Built to not make things up

The hardest problem in an AI research tool isn't generating opportunities. It's trusting them. Ugo is built around a small set of hard rules that constrain what the models are allowed to assert.

≥2 sources

Every claim needs sources

No statement in a brief stands on one article. Each one is required to trace back to at least two independent source IDs.

data APIs

Numbers come from data, not prose

Market-size figures are pulled from FRED, the World Bank and Statista, never generated by a language model.

critic agent

A critic reviews every output

A dedicated critic agent checks each other agent's output before it's allowed into the brief. Nothing ships unreviewed.
